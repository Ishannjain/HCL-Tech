# Fee calculation
For this synthetic hackathon dataset only, restocking fee is 10% of net item price times quantity. Reverse shipping fee is INR 60 per return request. Round each monetary amount to two decimal places using ROUND_HALF_UP.
# Approval
For this synthetic hackathon dataset only, automatic refund approval limit is INR 10000 inclusive. An estimate above the limit requires human approval. No tool issues money.
# Warranty
For synthetic products, warranty starts on delivery and lasts the product record warranty_months in calendar months, inclusive of the calendar expiry date. Brand installation and exclusions still require verification.
# Nonreturnable category
For this synthetic dataset only, AUDIO is a non-returnable category for all return reasons.
